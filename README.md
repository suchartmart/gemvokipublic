## app-ads.txt

This repository includes the publisher's app-ads.txt file, but a project Pages URL such as
`https://suchartmart.github.io/gemvokipublic/app-ads.txt` is not the domain-root endpoint AdMob looks for.
Arrange `https://suchartmart.github.io/app-ads.txt` through the account-level Pages site, or use a custom domain
for this repository. No account-level repository or custom domain has been created or modified here.

Reference: https://support.google.com/admob/answer/9363762
